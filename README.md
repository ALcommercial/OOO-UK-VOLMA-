# ВОЛМА · Умная логистика (MVP)

Десктоп-приложение на Python для управления цепочками поставок ООО «УК «ВОЛМА»: 9 заводов, 4 месторождения гипса, распределительные центры в России и Казахстане. Встроенный ИИ-модуль подбирает оптимальные маршруты с учётом дорожной обстановки, распределяет заказы по машинам без холостых пробегов и оценивает риск потерь груза.

## Запуск

Нужен Python 3.9+ (Windows: стандартный установщик с python.org, Tkinter входит в комплект). Сторонние библиотеки не требуются.

```
python main.py
```

или двойной щелчок по `run.bat`. При первом запуске создаётся локальная база `data/volma.db` с демонстрационными данными, и модель трафика обучается за доли секунды.

## Возможности

| Вкладка | Что делает |
|---|---|
| Обзор | KPI холдинга, карта сети, риски на дорогах, экономия ИИ по рейсам |
| Карта сети | Заводы, месторождения, РЦ, дороги с прогнозом загруженности на 72 часа, события, МАПП |
| Маршрут | Расчёт 3 лучших маршрутов (алгоритм Йена) и сравнение с традиционным кратчайшим путём |
| Заказы | Ввод заказов и оптимизация плана перевозок ИИ: консолидация, мульти-дроп, цепочки рейсов, обратная загрузка |
| Рейсы | Цепочки плеч (порожний / с грузом / возврат), отправка и закрытие рейсов, дообучение модели по телеметрии |
| Автопарк | Самосвалы, цементовозы, тенты: грузоподъёмность, расход, база, местоположение, ремонт |
| Дорожная обстановка | Ремонты, ДТП, пробки, перекрытия, погода по регионам, состояние покрытия |
| Аналитика ИИ | Точность модели (R², MAE), суточный профиль загруженности, вклад факторов, холостой пробег, структура затрат |
| Справочники | Экономические параметры (топливо, ставки, «Платон», веса критериев), объекты сети, типы грузов, экспорт CSV, сброс демо-данных |

## Как устроен ИИ-модуль

1. **Прогноз загруженности** (`volma/ai/traffic_model.py`). Гребневая регрессия на истории наблюдений трафика: час суток (утренний и вечерний пики), день недели, погода, дорожные события, качество покрытия, доля городских участков. Качество оценивается на отложенной выборке. После каждого закрытого рейса данные добавляются в историю и модель переобучается.
2. **Маршрутизация** (`volma/ai/network.py`). Зависящий от времени алгоритм Дейкстры: загруженность каждого участка прогнозируется на час, когда машина до него доедет. Обобщённая стоимость складывается из топлива (с учётом загрузки, пробок, покрытия, погоды), платных дорог и «Платона», времени водителя и ТС, ожидаемых потерь груза, задержек на МАПП и режима труда и отдыха. Вес каждого критерия задаётся отдельно: баланс, минимум затрат, скорость или сохранность груза. Перекрытые участки исключаются.
3. **Риск потерь груза**. Для каждого типа груза заданы базовые потери, чувствительность к покрытию и к погоде: гипсовый камень навалом, цемент, мешки, ГКЛ, ПГП.
4. **Диспетчеризация** (`volma/ai/dispatcher.py`). Крупные заказы делятся на рейсы, попутные заказы консолидируются, в том числе с несколькими точками выгрузки. Машины назначаются жадным алгоритмом с сожалением (regret) с учётом подачи порожняком, обратной загрузки, сроков и приоритетов. Затем план улучшается локальным поиском: перенос и перестановка рейсов между машинами. Результат сравнивается с традиционной схемой, где каждый заказ везёт машина своего завода по кратчайшему пути с возвратом порожняком.

## Структура

```
main.py                 точка входа
run.bat                 запуск в Windows
volma/db.py             SQLite: схема, доступ к данным, настройки
volma/seed.py           демонстрационные данные и синтетическая история трафика
volma/geo.py            геометрия и форматирование
volma/ai/               ИИ-модуль: модель трафика, сеть и маршруты, диспетчер
volma/ui/               интерфейс Tkinter: вкладки, карта, графики
```

## Данные

Площадки взяты с сайта volma.ru: Волгоград, ВТР (Волгоград), Воскресенск, Челябинск, Оренбург (п. Дубенский), Абсалямово, Майкоп (п. Каменномостский), Байкал (Ангарск), ИндерГипс (Казахстан). Названия и координаты месторождений, дорожный граф, расстояния, автопарк, заказы и история трафика в MVP демонстрационные. Все они хранятся в локальной базе и редактируются через интерфейс или напрямую в SQLite. Чтобы вернуть исходное состояние, на вкладке «Справочники» есть кнопка «Сбросить демо-данные».

## Сценарий демонстрации

1. «Обзор»: состав сети и текущие риски.
2. «Маршрут»: ИндерГипс → Саратов. Кратчайший путь идёт через закрытый МАПП Озинки, и ИИ строит объезд через Атырау и Астрахань.
3. «Дорожная обстановка»: кнопка «Получить обновление обстановки», затем пересчёт маршрута.
4. «Заказы» → «Оптимизировать план перевозок (ИИ)»: экономия затрат, холостого пробега и топлива. Затем «Утвердить план».
5. «Рейсы»: отправить и завершить рейс, модель дообучится. Результаты видны в «Аналитике ИИ».
